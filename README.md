## Requirements / Problem Statement
- Build a website for the Computer Society of India chapter.
- Must include: Hero section, About, Events, Team, and Contact/Join form.
- Should be fully responsive (mobile + desktop).
- Frontend only. Built on the spot during Round 2.
- Allowed to use AI and vibe-coding tools.

## Features
- [x] Responsive layout (mobile + desktop)
- [x] Sticky navbar with mobile hamburger menu
- [x] Hero section with CTA button
- [x] About section for the CSI chapter
- [x] Events showcase in a card grid
- [x] Team/Committee member profiles
- [x] Registration/Contact form with client-side validation
- [x] Smooth scrolling between sections
- [x] Footer with social links

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **UI Library:** React 18
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
- **Fonts:** next/font (Inter / Poppins)
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
